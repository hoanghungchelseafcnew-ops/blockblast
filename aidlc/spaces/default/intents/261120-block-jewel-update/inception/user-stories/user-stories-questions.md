# User Stories Plan and Questions

## Kế hoạch đề xuất

- **Persona:** 2 persona: Người chơi hành trình (Journey) và Chủ game / nhà phát triển (người phát hành). Không tách thêm persona Endless riêng, vì khác biệt chỉ là mức độ khó cố định.
- **Định dạng:** "As a [persona], I want [goal], so that [benefit]", tiêu chí chấp nhận Given/When/Then theo INVEST, mã `US{group}.{seq}` và `AC{group}.{seq}.{n}`.
- **Ưu tiên:** MoSCoW theo từng story.
- **Cách chia:** theo bốn nhóm yêu cầu (FR1 splash, FR2 đổi tên, FR3 chia sẻ, FR4 thuật toán khối), mỗi nhóm khoảng 2–4 story; ước lượng tổng 10–14 story.
